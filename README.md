# Student Academic Performance — Exploratory Data Analysis

## About the Project
This project performs Exploratory Data Analysis (EDA) on student academic performance data using Python, Pandas, NumPy, and Matplotlib.

## Objective
To combine data exploration, cleaning, statistical analysis, and visualization into a basic EDA workflow.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
The project contains 30 sample student records with the following columns:
- Student_ID
- Gender
- Study_Hours
- Attendance
- Exam_Score

The dataset was created for learning purposes. Missing values and a duplicate record were introduced to practise data cleaning.

## Steps Performed
1. Inspected the dataset structure and columns.
2. Checked missing values and duplicate records.
3. Filled missing numerical values using the median.
4. Filled missing categorical values using the mode.
5. Removed duplicate records.
6. Generated descriptive statistics.
7. Created four visualizations.
8. Calculated correlations between numerical variables.
9. Recorded meaningful observations.

## Visualizations
1. Exam Score Histogram
2. Student Gender Distribution Bar Chart
3. Study Hours vs Exam Score Scatter Plot
4. Attendance Box Plot

## Key Observations
- Exam scores are distributed across different score intervals.
- The bar chart compares the number of students in each gender category.
- The scatter plot helps explore the relationship between study hours and exam scores.
- The box plot displays the spread of attendance values and potential outliers.
- Correlation analysis helps examine relationships between numerical variables.
